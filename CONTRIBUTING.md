# Contributing

## AI-assisted development

Parts of this project may be written with AI assistance. AI-assisted
contributions are welcome, with two expectations:

- **You are responsible for what you submit.** Review, run, and stand
  behind every line, including generated code, as if you had written it by
  hand.
- **Disclose the assistance.** Add an `Assisted-by:` trailer to the commit
  message naming the tool, for example:

  Assisted-by: GitHub Copilot

  Assisted-by: Claude Code

  Use one trailer per tool when more than one was involved. Disclosure is a
  courtesy to reviewers and future maintainers; it is not a substitute for
  review, and it does not shift responsibility away from the submitter.

## Commit messages

Keep commit messages concise and in the imperative mood. When AI assistance
was used, append the `Assisted-by:` trailer described above.
